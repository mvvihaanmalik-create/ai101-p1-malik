# Context Kit

## Intent

The poster should feel like a deliberate contemporary-art exhibition piece: bold, spacious, slightly strange, and authored rather than like a generic AI illustration.

## Style note

Use a strict square composition, hard-edged flat forms, a limited three-colour system, strong asymmetry, and generous negative space. The exhibited AI artwork should be the focal point; any student figure should provide scale and curatorial context rather than become a character illustration. Avoid decorative clutter, literal robot imagery, generic circuitry, plants, furniture, and text.
