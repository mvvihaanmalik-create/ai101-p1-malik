# Step 1 — Define the goal: image-palette website preview

**Approved:** 2026-10-08

**Goal:** Build a small web app that takes one selected image, extracts a short palette of its main colors, and automatically tries those colors on a simple website preview before I commit to a design direction.

**Audience and environment:** I am a non-technical designer building and testing on a Windows computer. Other people should be able to open and use the app through a link on their phones.

**Input and output:** A user selects an image from their device. The app shows visible color swatches and a simple page preview. After image selection, extracted colors automatically fill the preview's background, text, and accent/button roles. A manual assignment step is not required.

**First-version requirements:** Image selection; main-color extraction and display; automatic mapping to the preview; visible update for each new image; an online link; and a usable phone-browser layout. Keep the prototype small enough to test before adding more features.

**Not required in the first version:** Manual color-role adjustment, copying color codes, saving/exporting palettes, contrast guidance, multiple layouts, accounts, or a link that preserves and shares a particular palette/preview state.

**Observable success:** A test image on Windows produces a compact palette that I recognize as representing important colors in the image and automatically updates the preview. A second person can open the app link on a phone and run the same upload-to-preview flow without a desktop-sized layout. Unsupported images or failures are visible rather than silently producing a misleading palette.

**Open for Step 2:** There is no fixed time or cost limit yet; compare likely effort and cost before asking me to choose one. Browser compatibility, supported image formats, extraction method, framework, and hosting route still need checking. Do not treat those choices as already approved.

**Check result:** I confirmed automatic color application, an online app shareable with phones, and Windows as my build/test computer. Step 1 is complete; stop before Step 2.
