# Intent

I want a square student AI-art pin-up poster that feels authored and exhibition-worthy: the viewer should sense that the student has made or presented something visually arresting, not just see a student illustrated in a studio. The work should be bold, strange, deliberate, and legible without words, using exactly three colours.

The later psychological-horror direction aims for unease through an impossible relationship between artist and artwork, dramatic perspective, and a coherent visual paradox—not gore or arbitrary horror decoration. This note was formalized during Class 3 on 2026-09-22 from the project's existing direction; it was not an input file in earlier rounds.
