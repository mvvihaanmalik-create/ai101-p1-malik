# ADR-016 · Separate exploration from the story

**Context.** I wanted visitors to explore the atmosphere without an active threat or score. The option was missing in my first review.

**Decision.** Add an empty-hotel mode from the title screen. Reuse the road, reception and four storeys, and let players take a shortcut from the car.

**Consequence.** Players can return outside or switch to the story without affecting the scoring rules. Codex checked the path and graphics recovery. The formal out-of-scope input test is still pending.
