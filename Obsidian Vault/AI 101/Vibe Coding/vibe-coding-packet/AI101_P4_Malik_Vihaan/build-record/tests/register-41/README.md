# The night register
I wanted every completed story to include every anomaly. After the ordinary visit, the hotel deals all twelve in shuffled order. I inspect a change and retreat to enter it in the register. The suite opens after the twelfth entry. Escape shows the last three entries.

Codex added a private, optional writing pass. In the linked Vercel project, save DEEPSEEK_API_KEY as a Sensitive Production environment variable and redeploy. The build asks DeepSeek Flash once for twelve short entries. Only the finished lines ship to the browser. A missing key, invalid answer or timeout keeps the authored entries. The game sends no player data to the provider.

Developer checks covered 200 shuffled runs including missed sightings and retries. Compression reduced the opening GLB files from 32,647,248 to 24,666,599 bytes. Every compressed model decoded to the original bytes. These are developer checks.
Fresh Chrome checks reached playable controls in 19.0 seconds on the preceding deployment and 16.9 seconds on v41. One sample per version. On the public build all twelve compressed GLBs loaded, room service scored after inspection and retreat, and Escape displayed its register entry. The local graphics recovery check also passed.
