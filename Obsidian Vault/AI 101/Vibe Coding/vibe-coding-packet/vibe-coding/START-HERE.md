# Project 4 packet

Every file you need for Project 4 is in this folder, already arranged the way the brief asks for. The full brief is on the course site: [Vibe Coding](https://ai-101-v4.vercel.app/projects/vibe-coding).

## Import it

1. Unzip the packet.
2. Drag the `vibe-coding` folder into your Obsidian vault, next to your `project-03` folder.
3. Open this file in Obsidian.

## Before you open any file: find your idea

Answer the spark questions in the brief on your own, with no AI. Write three ideas, one line each. Then test them with the ESF Companion in your vault tool. You choose the idea.
