# How I used AI

I chose the hotel, the observation mechanic, the influences and the ending. I directed the cast, the luggage puzzle, the sound, and the revisions. I asked for changes when the figures looked blocky, the hands looked fake, the rooms felt crowded, or the rules were unclear.

I used Codex to build the game, develop scenes and animation, adapt and credit assets, run developer checks, and record the walkthrough. The 3D workflow used headless Blender and Python scripts. The earlier moodboards used image generation.

I watched tests and gave feedback while Codex operated the controls. I also played and supplied my own feedback for Cycle 2. The testing record separates my observations from developer verification.
