# My four tests
I’ll start recording before the first input and keep the first attempt, including failures. For each test I’ll record the build, what happened, my observations and who operated the controls.

1. **Main path:** Learn the ordinary hotel, make four correct decisions, solve luggage claim, open the suite, pause the ending and replay.
2. **Edge case:** Escape the hostile butler for one point. Then allow contact and check for one reset and restored movement.
3. **Unexpected input:** Try walking during inspection and pause, then tap E rapidly. Check movement and score afterward.
4. **Out of scope:** Try F, Space and clicking against the ordinary butler. Check that the game stays responsive.
