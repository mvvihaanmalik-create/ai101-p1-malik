# The luggage room

**Route** Reception → ordinary tour → two correct decisions → luggage room → staff stair → four correct decisions → honeymoon suite → reception ending.

The porter takes one claim per run. Select a suitcase with A/D, press E to turn it toward the mirror and compare the reflected stamp with the ticket. Press E to claim it. A wrong match preserves 2/4. A match opens the staff stair. This room reuses the porter and suitcase models and adds one mirror.
