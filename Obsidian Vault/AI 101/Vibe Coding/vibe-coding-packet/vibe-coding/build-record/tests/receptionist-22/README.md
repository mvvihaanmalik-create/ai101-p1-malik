# Receptionist portrait study
I supplied a front-facing reference for the receptionist's face and hair. Codex fitted the oval face, cheek and jaw proportions, eyebrows, nose and smile on the existing MakeHuman rig. The hair has a side part, an exposed ear with a hoop and longer chestnut waves over the opposite shoulder. The side and back follow an inferred shape.
