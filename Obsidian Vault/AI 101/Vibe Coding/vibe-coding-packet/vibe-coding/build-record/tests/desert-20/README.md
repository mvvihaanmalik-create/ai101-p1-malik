# Desert arrival · Hotel of Horror

I wanted the driver to arrive for a reason. A flat tyre stops the car on a California desert highway. Steam rises from the bonnet, and the red hotel windows draw the driver past the palms to the entrance. A woman at reception welcomes the guest. The older butler appears later.

The exterior runs for 21 seconds, followed by the desk greeting. E skips each part and Escape pauses. Codex created the roadside scenery in Three.js and fitted the receptionist from CC0 MakeHuman assets in Blender.
