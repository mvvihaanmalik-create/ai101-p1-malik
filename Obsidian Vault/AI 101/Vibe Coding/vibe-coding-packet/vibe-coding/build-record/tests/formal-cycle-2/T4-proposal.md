# Cycle 2, Test 4 · Empty-hotel exploration proposal
November 13, 2026 · Planning note, not a completed test

I want an optional ambient mode where I can walk through the hotel without people, anomalies or scoring. It starts beside the broken car and lets me explore the hotel, with the song playing softly and slightly muffled. More interior details and spaces could be accessible than in the main game.

**Working name:** After Hours (suggestion, not final).

Before I build it, I need a clear architectural plan: the exterior approach, entrances, reception, stairs, four floors, connected halls, rooms and suite. Doors and transitions should correspond to that plan. “Every corner” needs a defined list of accessible spaces so the exploration feels complete.
