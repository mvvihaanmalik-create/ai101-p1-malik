# Room 0

[Play Room 0](https://room-zero-ashy.vercel.app/) · [Testing log](build-record/testing-and-failure-log.md) · [Cycle 2 test card](build-record/tests/formal-cycle-2/README.md)

The hotel's lift is broken. Reach the honeymoon suite by noticing what changes on the way up. The first visit is ordinary. After that, continue if nothing changed or walk back through the entrance if something did. At 2/4 the porter hands you a claim ticket. Match it to a suitcase in the mirror to open the staff stair. Four correct decisions in a row open the suite.

**Controls:** WASD or arrows to walk. E skips the porter’s welcome, inspects a clue or uses a door. Escape pauses and opens the night register. No combat.

**Run locally:** From `build/`, run `npm run dev`, then open [the local game](http://127.0.0.1:4170/). Use a desktop keyboard.
