# The gameplay loop
I chose the Exit 8 rule: continue when a passage is ordinary and turn back when something changes.

Each correct decision earns one floor. A wrong decision resets progress. Four correct decisions unlock the honeymoon suite. The opening tour is unscored so the player can learn the hotel first.

I wanted a little more activity than observation alone. The hostile butler can approach, and the luggage room adds one short mirror puzzle. I later removed the holy item so retreat carries the threat encounter.
