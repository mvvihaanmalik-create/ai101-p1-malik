# The four playtests

Start recording before the first input. Keep the original attempt, even if it fails. Record the build, what happened and Vihaan's feedback separately.

1. **Main path:** Learn the ordinary hotel, make four correct decisions, reach the suite, pause the ending and replay.
2. **Edge case:** Escape the anomalous butler with one point, then allow contact. Check that the reset happens once and walking works afterward.
3. **Unexpected input:** Try walking during inspection and pause. Tap E rapidly, then check that the player can still walk and has not scored by accident.
4. **Out of scope:** Try combat against the ordinary butler. [Use the v16 test card](test-4-v16.md).

For a formal run, use the [exact inputs, timings and original protocol](formal-test-protocol-full-record.md). T1–T3 used v13. T4 uses fixed v16. Record build and route differences when comparing results.
