## Art pass 02 assets, November 8

The live guest and butler now use CC0 MakeHuman humans, skin, fitted suits, formal shoes, hair and facial components, generated with the official MPFB tool and customized for Room 0. Each has a weighted 53-bone rig and authored animation clips. [Full selected asset list, sources, licenses and modifications](room-zero-character-assets.md). MPFB tooling is GPL-3.0; the selected graphical assets are CC0. License evidence is retained in `build/vendor/licenses/makehuman/`.

Revised plates are rendered from `build/assets/hotel-lighting-v2.blend`; character sources are packed in `build/assets/characters-v2.blend`. The studio character study is an actual Blender render, not an AI concept image. The art pass retains the original hotel, props, textures and synthesized audio.
