# ADR-006 · Repair the hands
November 10, 2026

**Why:** In [Test 1](../build-record/tests/formal-cycle-1/T1-result.md), I found the hotel characters’ hands and fingers fake and unnatural.

**My decision:** I asked for a repair. Codex reset arm corrections each frame, corrected finger-bend axes and eased the grips. It adjusted the glass handoff so the hands could reach it.

**Tradeoff:** The poses no longer accumulate rotation. A mechanical check does not settle whether they look realistic. [Repair evidence](../build-record/tests/repairs-14/README.md).
