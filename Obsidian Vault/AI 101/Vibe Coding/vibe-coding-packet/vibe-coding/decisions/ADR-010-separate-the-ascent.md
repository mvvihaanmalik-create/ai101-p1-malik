# ADR-010 · Give the encounters space
November 10, 2026

**Why:** In [Test 3](../build-record/tests/formal-cycle-1/T3-result.md), I disliked the crowding. I wanted stairs, multiple floors, longer hall shots and more time with anomalies.

**My decision:** I chose to distribute encounters across the east stair, west gallery and lift landing. I suggested a child’s head instead of the ball; the revised scene uses a porcelain likeness.

**Tradeoff:** The game reuses architecture across four progress floors. The full gathering is saved for the ending. This was a revision during Cycle 1, so the comparisons must identify the different builds.
