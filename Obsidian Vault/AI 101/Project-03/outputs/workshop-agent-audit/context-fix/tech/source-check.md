# Source check

October 27. The coordinator opened these primary documentation pages after the live Technologist run.

- [MDN button element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button): documents native button input and activation, including keyboard use.
- [MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter): documents background visual effects such as blur.
- [W3C technique C39](https://www.w3.org/WAI/WCAG22/Techniques/css/C39): describes using the user's reduced-motion preference to suppress CSS motion.

These sources support the stated platform behavior. They do not verify this prototype's full accessibility, visual quality, performance or compatibility on every device. The separate counter check used the local browser with mouse and keyboard.
