Recorded October 22, 2026. This is a new controlled comparison, not an original Project 2 run.

## Same request for both runs

Find up to four references from the supplied collection for Design Shelf: a visual design library with project context, a category slider, saved project boards, and a small research assistant. Cover navigation, motion, and readable glass UI where the sources support them. Check original source links and dates with public web search. Use existing IDs when possible. Keep unknown dates separate from the last-90-days collection. Say when a source cannot be checked. Do not add records, edit notes, change code, or approve a design.

## Shared context

`input.json` freezes the approved summary, public reference candidates, source guide, date, and request. Both runs receive the same bytes. Neither receives full notes, earlier outputs, or the other run's answer.

The baseline uses Project 2's Step 2 source-verification instruction without Pip's role. The agent run uses the existing `design-shelf/agent/pip.md` role. Both use the same structured output and tool restrictions. This isolates a source-checking subtask; it does not compare two complete feasibility runs.
