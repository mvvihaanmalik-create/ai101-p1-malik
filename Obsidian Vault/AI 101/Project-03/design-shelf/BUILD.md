# Design Shelf build

## User direction

"An interactive collection simple page" with references from the last 90 days, refreshed twice a month. It should use project notes to know what Vihaan is making, organize references by project type, and use a premium iOS/macOS-inspired glass interface with short labels.

## Scope

- Real source references, dated from original release/case-study evidence.
- Project summaries from selected Obsidian frontmatter; no raw note bodies.
- Visual gallery, project-aware ranking, category and focus filters, saved items, original source links, and note context.
- Private hosted library, local note bridge, cloud reference updates on the 1st and 15th.

## Check before delivery

- Verify original media and dates; unknown dates remain evergreen.
- Verify a note summary change reaches the project context without editing original records.
- Verify filters, project switching, source details, saves, and mobile layout.
- Verify hosted persistence and a real update/readback before scheduling.

## Evidence

Source evidence is in `data/source-audit.md`. Notes connector tests use disposable temporary notes. Existing workflow gates and the public idea.quest site are not changed by this build.
