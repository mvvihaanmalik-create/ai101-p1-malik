Four previews are direct MP4 demos: Linear Loops, Linear mobile review, Depth, and Apple Liquid Glass. Framer Skills and CMS List Field use official video thumbnails and link to the original videos.

Run Rob Run, HAOQI.DESIGN, and Glass xylophone have no extracted preview. Do not fill these with a fabricated screenshot or unrelated asset. Their sources still provide useful demos. Codrops HTML was readable through web tools, but direct metadata requests returned HTTP 403.

## Collection limits

No private LinkedIn or X material was read. No social posts, engagement counts, launch dates, or media URLs were invented. The starter collection uses publisher and creator sites. Social access needs a separate working connector or public source.

Reference summaries and category labels are editorial judgments. Future refreshes must verify dates again and preserve the last good library if a source fails. A refresh is not complete until actual new dated sources have been collected.
